# Evaluation Pilot (Phase-1 Review) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the measurement apparatus for the phase-1 review and produce three small, honestly labelled pilot results: a five-server RQ1 drift mini-corpus with false-alert counts for description-only and full-surface pins, a per-episode token and latency table read from session JSONL files, and a ten-question LongMemEval smoke with arms 1–2 and a first judge-agreement figure.

**Architecture:** A Python uv project at `air/eval/` drives the harness through the upstream Python SDK, one runtime per run, each run under its own `DSH_HOME`. The runtime is the checkout's `dsh` CLI on an `air-eval` profile: the standalone `sdk-minimal` tree plus one eval-only bundle (`air/bundles/air-eval`) that turns every upstream tool off and adds local model routes. All metrics come from standard session events; RQ1 results come from pure functions over collected tool-surface snapshots and need no model. LongMemEval histories are replayed into real sessions through a local OpenAI-compatible server that returns the recorded assistant turns.

**Tech Stack:** Python 3.12 via uv 0.12; upstream Python SDK (`python/sdk`, editable path dependency); `mcp` 2.2.0 (stdio client for the collector), `rfc8785` 0.1.4, `openai` (judge client), PyYAML, pytest; Cordis YAML patches; Ollama with `qwen2.5:7b-instruct`, `qwen3:8b`, `llama3.1:8b`; bubblewrap, npm, and uv for the RQ1 collector.

**Spec:** [air/plans/spikes/06-evaluation.md](spikes/06-evaluation.md) (primary: §3 drift corpus, §4 LongMemEval, §5 plumbing, §7 layout, §8 phase-1 pilot), [research/research.md](../../research/research.md) §6, [research/notes/07-product-fyp-strategy.md](../../research/notes/07-product-fyp-strategy.md) §3–4, [air/plans/spikes/03-mcp-trust.md](spikes/03-mcp-trust.md) §7 (digest definition), [python/sdk/README.md](../../python/sdk/README.md) and [python/development.md](../../python/development.md) (SDK driver and source runtime).

**Depends on:** [plan 00](2026-09-30-00-workspace-foundation.md) for `air/package.json` (`packageManager`), `air/pnpm-workspace.yaml`, and `air/.gitignore`. Plan 02 is not required; Task 5 cross-checks plan 02's golden digest file when it exists.

**Scope note:** spike 06 §8 lists four pilot items. Its first item, the AgentDojo banking run (native pipeline versus the undefended harness, with the MCP bridge and the eval approval answerer plugin), is the most expensive and has its own plan; its design, the facts already verified for it, and its effort are in "Follow-up plans" at the end.

## Global Constraints

- Python runs through uv only. The system Python is 3.14, but AgentDojo 0.1.35 (added to this project by the AgentDojo follow-up plan) declares support for Python 3.10–3.12 in its package classifiers, so the project pins **Python 3.12** now (`requires-python = ">=3.12,<3.13"`, `.python-version` `3.12`); uv installs that interpreter itself.
- Node `^22.19.0 || >=24.0.0`; pnpm `11.7.0`.
- Benchmark data is never committed when its licence is missing (MCPTox). AgentDojo, LongMemEval, and MSB are MIT. Record versions wherever a benchmark is named: AgentDojo package 0.1.35, benchmark version v1.2.2 (97 user tasks, 35 injection tasks, 949 attack pairs).
- Out-of-tree plugins cannot write custom session event types. Metrics come from standard session events (`assistant/message`, `step/start`, `step/end`, `tool/call`, `tool/result`, `approval/asked`, `approval/decided`, `turn/end`, `request/header`) and AIR JSONL files. No task may add a `SessionEventMap` member.
- Application launch: only `dsh` profiles launch Node applications. Manual steps use `pnpm dsh --profile air-eval ...`; Python uses the SDK's documented source route (`dsh_bin` set to the built `apps/cli/lib/bin.js`, which runs the same `dsh --profile` launcher). No package bins.
- Markdown written by this plan (READMEs, result tables): never use the banned origin-label word checked by `verify-concrete-terms`; no git commit hashes; no URLs under the upstream working organization on GitHub. SHA-256 file digests and `sha256:<hex>` tool digests are allowed.
- Every cost or time figure is labelled **estimate** or **measured**. A measured figure states its n.
- Every pilot table carries its n, "one repeat", and what it does not show. No pilot number is extrapolated to RQ1–RQ6.
- The eval bundle `@air/dsh-air-eval-bundle` never appears in the product bundle `air/bundles/air`.
- AIR install and every run happen only after a finished `pnpm install` and `pnpm run build` at the repository root.
- Git-ignored and never committed: `air/eval/data/`, `air/eval/runs/`, `air/eval/.venv/`.
- **Cross-platform commands.** Four teammates work on native Windows PowerShell without WSL, so every command in this plan is one `uv`, `pnpm`, `node`, `ollama`, or `git` invocation, or a Python script, that runs unchanged in bash and in PowerShell 5.1 or 7. A step names its working directory in its label (`from the repository root` or `from air/eval`); there is no `&&` chain (one command per line), heredoc, `mktemp`, `for` loop, `grep`, `cp`, `cat`, `wc`, or absolute home path. Paths are relative to the labelled directory and written with `/`, which both shells and Python accept. Python code uses `pathlib`, `tempfile`, `shutil.which`, explicit `encoding="utf-8"`, and `newline=""` for CSV; it uses no `os.fork`, no POSIX signals, and no `/tmp` literals outside the Linux-only sandbox command. Run directories nest deeply (`runs/<id>/home/sessions/...`), so on Windows clone the repository near the drive root, keep run ids short, and enable Windows long paths.
- **Linux-only step.** RQ1 collection (Task 7 Step 7) starts third-party MCP servers inside bubblewrap and runs on Linux only; on Windows it refuses to start and Windows teammates replay snapshots copied from a Linux run (Step 8 runs everywhere). Every other task runs on both systems. The SDK source route on Windows (Task 4 `runtime_launcher`) is written from the SDK source and has not been run on Windows; its first gate is the live test of Task 4.
- **Permission configuration of this plan's runs.** The eval composition is the standalone `sdk-minimal` tree plus the eval bundle. It has no approval service row, no permission-rule plugin, and no built-in tool row (every upstream tool row is off), so no run in this plan can ask for approval. Arm 2 enables the five session-search tools, which are built-in (not MCP) tools. Plan 03's rule that built-in tools allow by default therefore never applies here. The AgentDojo plan ([plan 06](2026-10-03-06-agentdojo-pilot.md)) is the first plan whose tools arrive as MCP tools; it states the permission configuration per arm.
- **Peer ranges.** This plan builds no TypeScript package. A package that a later plan adds to the eval bundle declares its upstream peers as `^0.2.0-rc.1 || ^0.2.1-alpha.1` (the form plan 03 uses).

## Facts verified while writing this plan (upstream `dsh-v0.2.0-rc.2`, 2026-10-01; re-checked at `dsh-v0.2.1-alpha.1`, 2026-10-08)

Every code file in this plan was run in a scratch directory before it was copied here. "Measured" figures are from this machine (RTX 4060 Laptop 8 GB, Ollama, Node 22.23.1, `qwen2.5:7b-instruct`).

1. **SDK source route.** `DeepSeekHarness(dsh_bin=<repo>/apps/cli/lib/bin.js, dsh_home=..., profile=..., patches=(...))` starts the checkout's CLI (the file is executable and starts with `#!/usr/bin/env node`). `provider="ollama"` with a hand-declared `llm-pi-ai` route and `OLLAMA_API_KEY=ollama` in the child environment completes a turn.
2. **Profile.** `dsh --profile air-eval --from-default-profile sdk-minimal --dump-config` creates a profile named `air-eval` from the standalone minimal tree; `dsh plugin --profile air-eval add <abs bundle dir>` links a local bundle in about 0.6 s (measured, n = 2) and needs `pnpm` on `PATH`. The SDK accepts `profile="air-eval"`.
3. **A row whose package the CLI does not depend on is skipped with only a stderr warning** (`1 entry did not activate`), and the runtime still starts. `@deepseek-ai/dsh-tool-session-query` is such a package; it resolves once the eval bundle lists it under `dependencies` with a `link:` path. Runners therefore assert the model-visible tool names from the first `request/header` event (`data.header.tools[].name`).
4. **Event fields.** Envelope `{type, seq, time, data}`. `assistant/message.data` has `turn`, `step`, `message.content[]`, `usage` (`inputTokens`, `outputTokens`, `totalTokens`, optional `cacheReadTokens`, `reasoningTokens`), and `stream` (records `chunk` with `time`; packed runs `text-chunks`, `reasoning-chunks`, `tool-call-chunks` with `time0` and `dt[]`). `tool/call.data` has `callId`, `name`, `arguments` (a JSON string). `tool/result.data.message` has `toolCallId`, `content[]`, `isError`. `turn/end.data.reason.kind` is the finish reason.
5. **Session files.** `$DSH_HOME/sessions/--<cwd with separators replaced>--/<session id>/session.v4.jsonl`; the first line is a `{"type":"session",...}` header; `sdk-minimal` already sets `compression: none`. Folding the file gives the same metrics as folding `RunResult.events`.
6. **The harness sends no `temperature`** to an `openai-completions` route (request keys: `model`, `messages`, `stream`, `stream_options`, `store`, `max_tokens`). Task 4 therefore creates Ollama model variants whose Modelfile fixes temperature 0, seed 7, and a 16,384-token context.
7. **MCP Python SDK 2.2.0:** `stdio_client(StdioServerParameters(command, args, env), errlog=...)`, `ClientSession(read, write, read_timeout_seconds=...)`, `initialize()`, `list_tools(params=PaginatedRequestParams(cursor=...))`; results use snake_case attributes (`protocol_version`, `server_info`, `next_cursor`) and serialize to wire names with `model_dump(by_alias=True, exclude_none=True, mode="json")`.
8. **RQ1 collection works for all five pilot servers** under `bwrap --unshare-net` with a read-only filesystem: about 5 s per version (measured, n = 11 versions, zero failures). An old PyPI release with open dependency ranges fails to start on current libraries; installing with `uv pip install --exclude-newer <release date + 1 day>` fixes it.
9. **LongMemEval.** The oracle file has 500 questions (133 temporal-reasoning, 133 multi-session, 78 knowledge-update, 70 single-session-user, 56 single-session-assistant, 30 single-session-preference; 30 abstention ids ending `_abs`); `answer` is an integer for 32 of them; some sessions start with an assistant turn and one has two consecutive same-role turns. The `llm-pi-ai` `openai-completions` route requests `stream: true`; a server that answers with three SSE frames (content, `finish_reason: stop`, usage) and `[DONE]` is accepted. Replay ingestion ran 29 turns in 1.3 s after runtime start (measured, n = 6 oracle questions); arm 2 exposes exactly `session_event_read`, `session_event_search`, `session_event_trace`, `session_search`, `session_trace`.
10. **Episode driver.** Five single-turn prompts ran in 0.4–3.4 s each (measured, n = 5; the first includes model load).
11. **Not verified here:** the `deepseek-flash` route and ingestion time on the LongMemEval S variant (about 500 turns per question). The Modelfile-derived Ollama models of Task 4 were created later; see item 14.
12. **Re-check at `dsh-v0.2.1-alpha.1` (2026-10-08, measured on the Fedora development laptop).** The composition check of Task 1 (run against a scratch copy of the bundle with absolute `link:` paths) printed `composition ok` (n = 1), and a patch that names a missing row id produced `patch: entry "no-such-row" not found` on stderr with exit code 0 from `--dump-config` (n = 1). The live test passed against the existing `air-eval-qwen25` model (1 passed in 8 s, n = 1): the first `request/header` lists no tools. A second run with the arm 2 patch listed exactly `session_event_read`, `session_event_search`, `session_event_trace`, `session_search`, `session_trace` (n = 1). Not run: anything on native Windows, the RQ1 collector (not changed apart from its platform guard), and the LongMemEval and episode tasks.

```python
"""Check that the air-eval profile composes over sdk-minimal as the evaluation plans assume.

Runs under any Python 3.9 or newer with the standard library only, on Linux and
native Windows: ``uv run --no-project python air/eval/scripts/check_composition.py``.
Creates its own throwaway DSH_HOME, so it never touches a developer profile.

import argparse
import json
import os
import re
import shutil
import subprocess
import sys
import tempfile
from pathlib import Path

REPO = Path(__file__).resolve().parents[3]

# Rows the eval bundle turns off by id. If upstream removes one, the patch logs
# `patch: entry "<id>" not found` and the check fails, so a stale list is noticed.
DISABLED_ROWS = (
    "persistent-bash",
    "persistent-pwsh",
    "mcp-resources",
    "session-log-deepseek",
    "plugin-package-inventory-deepseek",
)

# reading (non-minimal presets) would add model-visible tools, and plan 03's permission

ABSENT_ROW_PATTERN = re.compile(r"^- id: .*(schedule|time-context|reminder|air-permission-rules)", re.MULTILINE)


def run(argv: list[str], home: Path) -> subprocess.CompletedProcess[str]:
    """Run one command in the repository root with the throwaway DSH_HOME."""
    executable = shutil.which(argv[0])
    if executable is None:
        raise SystemExit(f"{argv[0]} is not on PATH")
    env = {**os.environ, "DSH_HOME": str(home)}
    return subprocess.run(
        [executable, *argv[1:]], cwd=REPO, env=env, capture_output=True, text=True, encoding="utf-8", timeout=600
    )


def row_block(dump: str, row_id: str) -> str:
    """Return the dump lines of one row, from its `- id:` line to the next row or layer header."""
    lines = dump.splitlines()
    for index, line in enumerate(lines):
        if line.strip() == f"- id: {row_id}":
            block = [line]
            for follower in lines[index + 1 :]:
                if follower.startswith("- ") or follower.startswith("#"):
                    break
                block.append(follower)
            return "\n".join(block)
    return ""


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--bundle", type=Path, default=REPO / "air" / "bundles" / "air-eval")
    parser.add_argument("--arm", type=Path, default=REPO / "air" / "eval" / "profiles" / "arms" / "rq3-arm2.patch.yml")
    parser.add_argument("--air-package", type=Path, default=REPO / "air" / "package.json")
    args = parser.parse_args(argv)

    problems: list[str] = []
    if not (REPO / "apps" / "cli" / "lib" / "bin.js").is_file():
        problems.append("apps/cli/lib/bin.js is missing: run `pnpm install` and `pnpm run build` at the repository root")
    if not (REPO / "packages" / "session-query" / "tool-session-query" / "lib" / "index.js").is_file():

    for package in ("dsh-session-query-sqlite", "dsh-tool-session-query"):
        if not (args.bundle / "node_modules" / "@deepseek-ai" / package).exists():
            problems.append(f"{args.bundle}/node_modules/@deepseek-ai/{package} is missing: run `pnpm -C air install`")
    manager = json.loads(args.air_package.read_text(encoding="utf-8")).get("packageManager", "")
    if not manager.startswith("pnpm@"):
        problems.append(f"{args.air_package} has no pnpm packageManager: finish plan 00")
    if problems:
        print("\n".join(problems), file=sys.stderr)

        home = Path(raw_home)
        steps = (
            ["pnpm", "dsh", "--profile", "air-eval", "--from-default-profile", "sdk-minimal", "--dump-config"],
            ["pnpm", "dsh", "plugin", "--profile", "air-eval", "add", str(args.bundle.resolve())],

        for step in steps:
            done = run(step, home)
            if done.returncode != 0:
                print(f"{' '.join(step)} failed ({done.returncode}):\n{done.stderr[-2000:]}", file=sys.stderr)
                return 1
        done = run(["pnpm", "dsh", "--profile", "air-eval", "--patch", str(args.arm.resolve()), "--dump-config"], home)
        if done.returncode != 0:
            print(f"final dump failed ({done.returncode}):\n{done.stderr[-2000:]}", file=sys.stderr)
            return 1
        dump, stderr = done.stdout, done.stderr

    for row_id in DISABLED_ROWS:
        if "disabled: true" not in row_block(dump, row_id):
            problems.append(f"row {row_id} is not disabled in the composed tree")
    if "@air/dsh-air-eval-bundle" not in dump:
        problems.append("the composed tree has no @air/dsh-air-eval-bundle layer")
    if args.arm.name not in dump:
        problems.append(f"the composed tree has no layer for {args.arm.name}")
    if ABSENT_ROW_PATTERN.search(dump):
        problems.append("the composition contains a schedule, time-context, reminder, or air-permission-rules row")
    bad = [line for line in stderr.splitlines() if re.search(r"not found|unmatched|incompatible|failed|did not activate", line)]
    problems += [f"stderr: {line}" for line in bad]

    if problems:
        print("\n".join(problems), file=sys.stderr)
        return 1
    print("composition ok")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Interval and agreement statistics used by the pilot tables."""

from __future__ import annotations

import math
from collections.abc import Sequence


def wilson_interval(successes: int, n: int, z: float = 1.959963984540054) -> tuple[float, float]:
    """Return the Wilson score interval for a binomial proportion.

    Returns (0.0, 1.0) when ``n`` is 0, because no observation constrains the proportion.
    """
    if n < 0 or successes < 0 or successes > n:
        raise ValueError(f"invalid counts: successes={successes}, n={n}")
    if n == 0:
        return (0.0, 1.0)
    p = successes / n
    denom = 1 + z * z / n
    centre = (p + z * z / (2 * n)) / denom
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / denom
    return (max(0.0, centre - half), min(1.0, centre + half))


def raw_agreement(a: Sequence[bool], b: Sequence[bool]) -> float:
    """Return the share of items on which two raters gave the same label."""
    if len(a) != len(b) or not a:
        raise ValueError("raters need the same non-zero number of labels")
    return sum(x == y for x, y in zip(a, b)) / len(a)


def cohen_kappa(a: Sequence[bool], b: Sequence[bool]) -> float:
    """Return Cohen's kappa for two binary raters.

    Returns 1.0 when both raters gave one identical constant label, where
    chance agreement is 1 and kappa is otherwise undefined.
    """
    po = raw_agreement(a, b)
    n = len(a)
    pa, pb = sum(a) / n, sum(b) / n
    pe = pa * pb + (1 - pa) * (1 - pb)
    if pe == 1.0:
        return 1.0
    return (po - pe) / (1 - pe)
```

```python
"""Fold standard session events into per-episode token and latency metrics.

The field definitions follow the upstream ``session-stats`` projection:
``llm_ms`` sums ``assistant/message.time - step/start.time``, ``ttft_ms`` sums
first-token time minus step start, ``decode_ms`` sums message time minus first
token for steps that report usage, and ``tool_ms`` sums matched
``tool/call`` to ``tool/result`` wall time.
"""

from __future__ import annotations

import json
import re
from dataclasses import asdict, dataclass, field
from pathlib import Path
from typing import Any

Event = dict[str, Any]


@dataclass(slots=True)
class EpisodeMetrics:
    turns: int = 0
    steps: int = 0
    input_tokens: int = 0
    output_tokens: int = 0
    cache_read_tokens: int = 0
    reasoning_tokens: int = 0
    llm_ms: int = 0
    tool_ms: int = 0
    ttft_ms: int = 0
    ttft_steps: int = 0
    decode_ms: int = 0
    decode_tokens: int = 0
    tool_calls: int = 0
    tool_errors: int = 0
    approvals_asked: int = 0
    approvals_allowed: int = 0
    finish_reason: str | None = None
    tool_names: list[str] = field(default_factory=list)

    def to_row(self) -> dict[str, Any]:
        row = asdict(self)
        row["tool_names"] = " ".join(self.tool_names)
        return row


def first_token_time(stream: list[dict[str, Any]]) -> int | None:
    """Return the time of the first token delta in a compact stream, or None."""
    for record in stream:
        kind = record.get("type")
        if kind == "chunk":
            chunk = record.get("chunk", {})
            ctype = chunk.get("type")
            if ctype in ("text-delta", "reasoning-delta") and chunk.get("text", "") != "":
                return int(record["time"])
            if ctype == "tool-call-delta" and (chunk.get("argumentsDelta", "") != "" or "name" in chunk):
                return int(record["time"])
            continue
        if kind == "tool-call-chunks" and "name" in record:
            return int(record["time0"])
        fragments = record.get("args") if kind == "tool-call-chunks" else record.get("texts")
        if not isinstance(fragments, list):
            continue
        time = int(record["time0"])
        deltas = record.get("dt", [])
        for index, fragment in enumerate(fragments):
            if index > 0:
                time += int(deltas[index - 1])
            if fragment != "":
                return time
    return None


def _usage_int(usage: Any, key: str) -> int:
    value = usage.get(key) if isinstance(usage, dict) else None
    return int(value) if isinstance(value, (int, float)) and value >= 0 else 0


def fold_events(events: list[Event]) -> EpisodeMetrics:
    """Fold root-session events of one episode into metrics."""
    m = EpisodeMetrics()
    open_step: tuple[int, int, int] | None = None  # (turn, step, start time)
    pending: dict[str, int] = {}
    last_turn: int | None = None
    for event in events:
        kind = event.get("type")
        data = event.get("data") or {}
        time = int(event.get("time", 0))
        if kind == "step/start":
            open_step = (data["turn"], data["step"], time)
        elif kind == "assistant/message":
            usage = data.get("usage")
            m.input_tokens += _usage_int(usage, "inputTokens")
            m.output_tokens += _usage_int(usage, "outputTokens")
            m.cache_read_tokens += _usage_int(usage, "cacheReadTokens")
            m.reasoning_tokens += _usage_int(usage, "reasoningTokens")
            if open_step is not None and open_step[:2] == (data.get("turn"), data.get("step")):
                start = open_step[2]
                open_step = None
                m.llm_ms += max(0, time - start)
                first = first_token_time(data.get("stream") or [])
                if first is not None:
                    m.ttft_ms += max(0, first - start)
                    m.ttft_steps += 1
                    if isinstance(usage, dict) and isinstance(usage.get("outputTokens"), (int, float)):
                        m.decode_ms += max(0, time - first)
                        m.decode_tokens += int(usage["outputTokens"])
        elif kind == "tool/call":
            pending[data["callId"]] = time
            m.tool_calls += 1
            m.tool_names.append(data["name"])
        elif kind == "tool/result":
            message = data.get("message") or {}
            call_id = message.get("toolCallId")
            if message.get("isError") is True:
                m.tool_errors += 1
            if call_id in pending:
                m.tool_ms += max(0, time - pending.pop(call_id))
        elif kind == "approval/asked":
            m.approvals_asked += 1
        elif kind == "approval/decided":
            if data.get("outcome") == "allowed-once":
                m.approvals_allowed += 1
        elif kind == "step/end":
            if last_turn != data.get("turn"):
                m.turns += 1
            last_turn = data.get("turn")
            m.steps += 1
            open_step = None
        elif kind == "turn/end":
            pending.clear()
            reason = data.get("reason")
            m.finish_reason = reason.get("kind") if isinstance(reason, dict) else None
    return m


_GENERATION = re.compile(r"^session\.v(\d+)\.jsonl$")


def session_log_path(dsh_home: Path, session_id: str) -> Path:
    """Return the highest-generation JSONL log of a session under a DSH home.

    Raises FileNotFoundError when the session has no uncompressed log, which
    also covers a profile that did not set ``compression: none``.
    """
    candidates: list[tuple[int, Path]] = []
    for directory in (dsh_home / "sessions").glob(f"*/{session_id}"):
        for path in directory.iterdir():
            match = _GENERATION.match(path.name)
            if match:
                candidates.append((int(match.group(1)), path))
    if not candidates:
        raise FileNotFoundError(f"no session.v<N>.jsonl for session {session_id!r} under {dsh_home}")
    return max(candidates)[1]


def read_session_events(path: Path) -> list[Event]:
    """Read the events of one session JSONL file, skipping the header line."""
    events: list[Event] = []
    with path.open(encoding="utf-8") as handle:
        for line in handle:
            if not line.strip():
                continue
            record = json.loads(line)
            if record.get("type") == "session":
                continue
            events.append(record)
    return events
```

```python
"""Per-run DSH_HOME, ``air-eval`` profile initialisation, run manifest, and SDK runtime factory.

Every run owns ``<runs>/<run-id>/`` with ``home/`` (the isolated DSH_HOME),
``workspace/`` (the agent cwd), and ``manifest.json``. The runtime is the
checkout's built ``dsh`` CLI selected through the SDK's ``dsh_bin`` option; the
only application entry is ``dsh --profile air-eval``.
"""

from __future__ import annotations

import hashlib
import json
import os
import platform
import shutil
import subprocess
import time
from dataclasses import dataclass
from pathlib import Path
from typing import Any

from deepseek_harness import DeepSeekHarness

PROFILE = "air-eval"
REPO_ROOT = Path(__file__).resolve().parents[4]
EVAL_ROOT = REPO_ROOT / "air" / "eval"
DSH_BIN = REPO_ROOT / "apps" / "cli" / "lib" / "bin.js"
EVAL_BUNDLE = REPO_ROOT / "air" / "bundles" / "air-eval"
ARMS_DIR = EVAL_ROOT / "profiles" / "arms"


class ProfileError(RuntimeError):
    """The ``air-eval`` profile could not be created or does not compose as required."""


@dataclass(slots=True)
class RunDir:
    """Paths of one run: ``home`` is the DSH_HOME, ``workspace`` the agent cwd."""

    root: Path
    home: Path
    workspace: Path

    @classmethod
    def at(cls, root: Path) -> "RunDir":
        return cls(root=root, home=root / "home", workspace=root / "workspace")


def _node() -> str:
    node = shutil.which("node")
    if node is None:
        raise ProfileError("node is not on PATH")
    return node


def _dsh(home: Path, *args: str) -> subprocess.CompletedProcess[str]:
    env = {**os.environ, "DSH_HOME": str(home)}
    return subprocess.run(
        [_node(), str(DSH_BIN), *args], env=env, capture_output=True, text=True, encoding="utf-8", timeout=300
    )


def create_run(run_id: str, runs_root: Path | None = None, *, with_profile: bool = True) -> RunDir:
    """Create a run directory and, unless ``with_profile`` is false, an ``air-eval`` profile in its own DSH_HOME.

    Raises ``ProfileError`` when the run id is taken, the CLI is not built, a
    command fails, or the composed tree lacks the eval bundle layer.
    """
    run = RunDir.at((runs_root or EVAL_ROOT / "runs") / run_id)
    if run.root.exists():
        raise ProfileError(f"run directory {run.root} already exists; choose a new run id")
    if not with_profile:
        run.root.mkdir(parents=True)
        return run
    if not DSH_BIN.is_file():
        raise ProfileError(f"{DSH_BIN} is missing: run `pnpm install` and `pnpm run build` at the repository root")
    if not (EVAL_BUNDLE / "node_modules").is_dir():
        raise ProfileError(f"{EVAL_BUNDLE}/node_modules is missing: run `pnpm -C air install`")
    run.home.mkdir(parents=True)
    run.workspace.mkdir()
    steps = (
        ("--profile", PROFILE, "--from-default-profile", "sdk-minimal", "--dump-config"),
        ("plugin", "--profile", PROFILE, "add", str(EVAL_BUNDLE)),
        ("--profile", PROFILE, "--dump-config"),
    )
    dump = ""
    for args in steps:
        done = _dsh(run.home, *args)
        if done.returncode != 0:
            raise ProfileError(f"dsh {' '.join(args)} failed ({done.returncode}): {done.stderr[-2000:]}")
        dump = done.stdout
    if "@air/dsh-air-eval-bundle" not in dump:
        raise ProfileError("composed air-eval profile does not contain the @air/dsh-air-eval-bundle layer")
    (run.root / "composed.cordis.yml").write_text(dump, encoding="utf-8")
    return run


def arm_patch(name: str) -> Path:
    """Return the absolute path of a committed arm patch, failing loud when it does not exist."""
    path = ARMS_DIR / f"{name}.patch.yml"
    if not path.is_file():
        raise FileNotFoundError(f"unknown arm patch {path}")
    return path


def runtime_launcher(run: RunDir, *, windows: bool | None = None) -> str:
    """Return the ``dsh_bin`` value that starts the checkout's built CLI.

    POSIX spawns ``bin.js`` itself (it is executable and has a node shebang).
    Windows cannot spawn a ``.js`` file, so a one-line ``.cmd`` shim that calls
    ``node`` is written into the run directory. ``windows`` overrides the
    platform check for tests.
    """
    if windows is None:
        windows = os.name == "nt"
    if not windows:
        return str(DSH_BIN)
    shim = run.root / "dsh-node.cmd"
    shim.write_bytes(f'@echo off\r\n"{_node()}" "{DSH_BIN}" %*\r\n'.encode("utf-8"))
    return str(shim)


def open_harness(
    run: RunDir,
    *,
    provider: str,
    model: str,
    patches: tuple[Path, ...] = (),
    env: dict[str, str] | None = None,
    max_tokens: int | None = None,
    request_timeout_seconds: float | None = 900.0,
) -> DeepSeekHarness:
    """Return an unstarted SDK harness bound to the run's DSH_HOME and the ``air-eval`` profile."""
    return DeepSeekHarness(
        dsh_home=str(run.home),
        cwd=str(run.workspace),
        dsh_bin=runtime_launcher(run),
        profile=PROFILE,
        patches=tuple(str(p) for p in patches),
        provider=provider,
        model=model,
        max_tokens=max_tokens,
        env={"OLLAMA_API_KEY": "ollama", **(env or {})},
        initialize_timeout_seconds=120.0,
        request_timeout_seconds=request_timeout_seconds,
        shutdown_timeout_seconds=10.0,
    )


def advertised_tools(events: list[dict[str, Any]]) -> list[str]:
    """Return the tool names of the first ``request/header`` in an episode's events."""
    for event in events:
        if event.get("type") == "request/header":
            return [tool["name"] for tool in event["data"]["header"].get("tools", [])]
    return []


def _git(*args: str) -> str:
    return subprocess.run(["git", "-C", str(REPO_ROOT), *args], capture_output=True, text=True, check=True).stdout.strip()


def sha256_file(path: Path) -> str:
    """Return the SHA-256 hex digest of a file."""
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for block in iter(lambda: handle.read(1 << 20), b""):
            digest.update(block)
    return digest.hexdigest()


def ollama_model_digest(model: str) -> str | None:
    """Return the Ollama model id from ``ollama list``, or None when the model or Ollama is absent."""
    try:
        out = subprocess.run(["ollama", "list"], capture_output=True, text=True, timeout=30).stdout
    except (OSError, subprocess.TimeoutExpired):
        return None
    for line in out.splitlines()[1:]:
        parts = line.split()
        if parts and parts[0] in (model, f"{model}:latest"):
            return parts[1]
    return None


def write_manifest(run: RunDir, **fields: Any) -> Path:
    """Write ``manifest.json`` with the fixed environment facts plus the caller's experiment fields."""
    root_package = json.loads((REPO_ROOT / "package.json").read_text(encoding="utf-8"))
    gpu = ""
    if shutil.which("nvidia-smi") is not None:
        gpu = subprocess.run(
            ["nvidia-smi", "--query-gpu=name,memory.total", "--format=csv,noheader"], capture_output=True, text=True
        ).stdout.strip()
    manifest = {
        "written_at": time.strftime("%Y-%m-%dT%H:%M:%S%z"),
        "harness_version": root_package["version"],
        "git_revision": _git("rev-parse", "HEAD"),
        "git_dirty": bool(_git("status", "--porcelain")),
        "profile": PROFILE,
        "host": platform.node(),
        "platform": platform.platform(),
        "python": platform.python_version(),
        "gpu": gpu,
        **fields,
    }
    path = run.root / "manifest.json"
    path.write_text(json.dumps(manifest, indent=2, sort_keys=True, default=str) + "\n", encoding="utf-8")
    return path
```

`REPO_ROOT` is `parents[4]` of `air/eval/src/air_eval/harness.py`. `dsh_bin` is the SDK's documented contributor route to the checkout's CLI (python/development.md, "Run against Node source"); it launches `dsh --profile air-eval` like any other caller. The SDK spawns `dsh_bin` directly without a shell (`python/sdk/src/deepseek_harness/client.py`, `_default_launch_args`), which is why `runtime_launcher` exists; the `.cmd` shim passes stdio through `cmd.exe` and has not been run on Windows. The manifest's `git_revision` is written into `runs/`, which is git-ignored, never into Markdown.

```python
"""RFC 8785 (JCS) plus SHA-256 digests of MCP tool surfaces.

The digest inputs follow spike 03 section 7 so that this module and the
TypeScript ``@air/dsh-mcp-trust`` package produce identical values:

- ``tool_digest = sha256(JCS({name, title?, description?, inputSchema, outputSchema?, annotations?, execution?}))``
- ``instructions_digest = sha256(UTF-8 text with trailing whitespace removed)``, or null for no or empty text
- ``surface_digest = sha256(JCS({instructions: instructions_digest | null, tools: {rawName: tool_digest}}))``

Absent fields are omitted, never written as null. Strings are not Unicode
normalized. Values that are not I-JSON are rejected with ``NotIJsonError``.
"""

from __future__ import annotations

import hashlib
import math
from collections.abc import Mapping, Sequence
from typing import Any

import rfc8785

TOOL_FIELDS = ("name", "title", "description", "inputSchema", "outputSchema", "annotations", "execution")
"""Tool definition fields covered by the digest, in lockfile order."""

# ECMAScript WhiteSpace and LineTerminator code points, which String.prototype.trimEnd removes.
_JS_TRIM = "\t\n\v\f\r                  　﻿"


class NotIJsonError(ValueError):
    """The value cannot be canonicalized: it is not I-JSON."""


def _check_string(value: str, where: str) -> None:
    try:
        value.encode("utf-8")
    except UnicodeEncodeError as exc:
        raise NotIJsonError(f"lone surrogate in {where}") from exc


def check_ijson(value: Any, where: str = "$") -> None:
    """Raise ``NotIJsonError`` unless ``value`` is plain I-JSON data."""
    if value is None or isinstance(value, bool):
        return
    if isinstance(value, str):
        _check_string(value, where)
        return
    if isinstance(value, int):
        if abs(value) > 2**53 - 1:
            raise NotIJsonError(f"integer outside the IEEE 754 exact range at {where}")
        return
    if isinstance(value, float):
        if not math.isfinite(value):
            raise NotIJsonError(f"non-finite number at {where}")
        return
    if isinstance(value, Mapping):
        for key, item in value.items():
            if not isinstance(key, str):
                raise NotIJsonError(f"non-string key at {where}")
            _check_string(key, f"{where} key")
            check_ijson(item, f"{where}.{key}")
        return
    if isinstance(value, Sequence):
        for index, item in enumerate(value):
            check_ijson(item, f"{where}[{index}]")
        return
    raise NotIJsonError(f"unsupported type {type(value).__name__} at {where}")


def canonical_bytes(value: Any) -> bytes:
    """Return the RFC 8785 canonical UTF-8 encoding of an I-JSON value."""
    check_ijson(value)
    return rfc8785.dumps(value)


def sha256_digest(value: Any) -> str:
    """Return ``sha256:<hex>`` over the canonical encoding of ``value``."""
    return "sha256:" + hashlib.sha256(canonical_bytes(value)).hexdigest()


def tool_digest_input(tool: Mapping[str, Any]) -> dict[str, Any]:
    """Project a tool definition onto the digested fields, omitting absent ones."""
    if "name" not in tool or "inputSchema" not in tool:
        raise ValueError("a tool definition needs name and inputSchema")
    return {key: tool[key] for key in TOOL_FIELDS if key in tool and tool[key] is not None}


def tool_digest(tool: Mapping[str, Any]) -> str:
    """Return the full-surface digest of one tool definition."""
    return sha256_digest(tool_digest_input(tool))


def field_digests(tool: Mapping[str, Any]) -> dict[str, str]:
    """Return one digest per present digested field of a tool definition, except ``name``."""
    return {key: sha256_digest(value) for key, value in tool_digest_input(tool).items() if key != "name"}


def instructions_digest(instructions: str | None) -> str | None:
    """Return the digest of the raw UTF-8 instructions text with trailing whitespace removed.

    Returns None when there are no instructions or the trimmed text is empty.
    """
    text = (instructions or "").rstrip(_JS_TRIM)
    if text == "":
        return None
    _check_string(text, "instructions")
    return "sha256:" + hashlib.sha256(text.encode("utf-8")).hexdigest()


def surface_digest(tools: Sequence[Mapping[str, Any]], instructions: str | None) -> str:
    """Return the digest of a whole server surface: instructions plus every tool."""
    names = [tool["name"] for tool in tools]
    if len(set(names)) != len(names):
        raise ValueError("duplicate tool name in surface")
    return sha256_digest(
        {"instructions": instructions_digest(instructions), "tools": {tool["name"]: tool_digest(tool) for tool in tools}}
    )


def description_digest(tool: Mapping[str, Any]) -> str:
    """Return the description-only pin of a tool: the digest of its description string.

    This models the baseline that hashes only the description. An absent
    description hashes as the empty string.
    """
    return sha256_digest(tool.get("description") or "")
```

```python
"""Classify the change between two snapshots of one MCP server's surface.

A snapshot is the JSON record written by ``collect.py``; only ``tools`` (wire
form, camelCase keys) and ``instructions`` are read here.
"""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass, field
from typing import Any

from air_eval.digests import field_digests, instructions_digest

Snapshot = Mapping[str, Any]

CLASS_ORDER = (
    "capability-expansion",
    "tool-removed",
    "schema-change",
    "annotation-or-output-change",
    "instructions-change",
    "description-change",
    "identical",
)
"""Primary class precedence: the first label present names the transition.

``description-change`` is primary only when no other label is present, so as a
primary class it means a description-only (or title-only) change.
"""


@dataclass(slots=True)
class Transition:
    added: list[str] = field(default_factory=list)
    removed: list[str] = field(default_factory=list)
    changed: dict[str, list[str]] = field(default_factory=dict)
    instructions_changed: bool = False
    labels: set[str] = field(default_factory=set)
    expansions: list[str] = field(default_factory=list)

    @property
    def primary(self) -> str:
        return next(label for label in CLASS_ORDER if label in self.labels)


def _types(schema: Mapping[str, Any]) -> set[str] | None:
    value = schema.get("type")
    if isinstance(value, str):
        return {value}
    if isinstance(value, list) and all(isinstance(item, str) for item in value):
        return set(value)
    return None


def _schema_expansions(tool: str, old: Any, new: Any) -> list[str]:
    """Return reasons the new input schema accepts more than the old one (top-level properties only)."""
    if not isinstance(old, Mapping) or not isinstance(new, Mapping):
        return []
    reasons: list[str] = []
    old_props = old.get("properties") if isinstance(old.get("properties"), Mapping) else {}
    new_props = new.get("properties") if isinstance(new.get("properties"), Mapping) else {}
    for name in sorted(set(new_props) - set(old_props)):
        reasons.append(f"{tool}: new parameter {name}")
    for name in sorted(set(new_props) & set(old_props)):
        before, after = old_props[name], new_props[name]
        if not isinstance(before, Mapping) or not isinstance(after, Mapping):
            continue
        old_enum, new_enum = before.get("enum"), after.get("enum")
        if isinstance(old_enum, list) and (
            not isinstance(new_enum, list) or any(item not in old_enum for item in new_enum)
        ):
            reasons.append(f"{tool}: widened enum {name}")
        old_types, new_types = _types(before), _types(after)
        if old_types is not None and (new_types is None or not new_types <= old_types):
            reasons.append(f"{tool}: widened type {name}")
    return reasons


def _annotation_expansions(tool: str, old: Any, new: Any) -> list[str]:
    old = old if isinstance(old, Mapping) else {}
    new = new if isinstance(new, Mapping) else {}
    reasons: list[str] = []
    if old.get("readOnlyHint") is True and new.get("readOnlyHint") is not True:
        reasons.append(f"{tool}: readOnlyHint no longer true")
    if old.get("destructiveHint") is False and new.get("destructiveHint") is not False:
        reasons.append(f"{tool}: destructiveHint no longer false")
    return reasons


def classify(old: Snapshot, new: Snapshot) -> Transition:
    """Compare two snapshots and label the transition."""
    old_tools = {tool["name"]: tool for tool in old["tools"]}
    new_tools = {tool["name"]: tool for tool in new["tools"]}
    t = Transition(
        added=sorted(set(new_tools) - set(old_tools)),
        removed=sorted(set(old_tools) - set(new_tools)),
        instructions_changed=instructions_digest(old.get("instructions")) != instructions_digest(new.get("instructions")),
    )
    for name in sorted(set(old_tools) & set(new_tools)):
        before, after = field_digests(old_tools[name]), field_digests(new_tools[name])
        fields = sorted(key for key in set(before) | set(after) if before.get(key) != after.get(key))
        if not fields:
            continue
        t.changed[name] = fields
        t.expansions += _schema_expansions(name, old_tools[name].get("inputSchema"), new_tools[name].get("inputSchema"))
        t.expansions += _annotation_expansions(name, old_tools[name].get("annotations"), new_tools[name].get("annotations"))
    t.expansions = [f"new tool {name}" for name in t.added] + t.expansions
    changed_fields = {f for fields in t.changed.values() for f in fields}
    if t.expansions:
        t.labels.add("capability-expansion")
    if t.removed:
        t.labels.add("tool-removed")
    if "inputSchema" in changed_fields:
        t.labels.add("schema-change")
    if changed_fields & {"outputSchema", "annotations", "execution"}:
        t.labels.add("annotation-or-output-change")
    if t.instructions_changed:
        t.labels.add("instructions-change")
    if changed_fields & {"description", "title"}:
        t.labels.add("description-change")
    if not t.labels:
        t.labels.add("identical")
    return t
```

```python
"""Pinning schemes replayed over a transition between two snapshots.

Each scheme is a pure function ``(old, new) -> bool`` that answers: would a
client that pinned ``old`` under this scheme raise an alert when it sees ``new``?
"""

from __future__ import annotations

from collections.abc import Callable

from air_eval.digests import description_digest, surface_digest
from air_eval.rq1.classify import Snapshot, classify


def flags_none(old: Snapshot, new: Snapshot) -> bool:
    """No pinning: never alerts."""
    return False


def flags_description_only(old: Snapshot, new: Snapshot) -> bool:
    """Alert when a tool present in both snapshots changed its description digest."""
    before = {tool["name"]: description_digest(tool) for tool in old["tools"]}
    return any(
        tool["name"] in before and before[tool["name"]] != description_digest(tool) for tool in new["tools"]
    )


def flags_description_only_strict(old: Snapshot, new: Snapshot) -> bool:
    """Description-only pinning that also treats a tool with no pin as drift."""
    known = {tool["name"] for tool in old["tools"]}
    return flags_description_only(old, new) or any(tool["name"] not in known for tool in new["tools"])


def flags_full_surface(old: Snapshot, new: Snapshot) -> bool:
    """Alert when the surface digest (instructions plus every tool definition) differs."""
    return surface_digest(old["tools"], old.get("instructions")) != surface_digest(new["tools"], new.get("instructions"))


def flags_full_surface_expansion_only(old: Snapshot, new: Snapshot) -> bool:
    """Full-surface pinning that alerts only when the classifier finds a capability expansion."""
    return flags_full_surface(old, new) and "capability-expansion" in classify(old, new).labels


SCHEMES: dict[str, Callable[[Snapshot, Snapshot], bool]] = {
    "none": flags_none,
    "description-only": flags_description_only,
    "description-only-strict": flags_description_only_strict,
    "full-surface": flags_full_surface,
    "full-surface+expansion": flags_full_surface_expansion_only,
}
```

```python
"""Collect one tool-surface snapshot per stable release of each candidate MCP server.

Each version is installed into a fresh temporary directory, started over stdio
inside a bubblewrap sandbox with no network, asked for ``initialize`` and
``tools/list``, and removed again. One JSON record per version is written under
``<out>/<ecosystem>/<package>/<version>.json``; existing records are kept, so
an interrupted collection resumes.
"""

from __future__ import annotations

import argparse
import asyncio
import json
import re
import shutil
import subprocess
import sys
import tempfile
import urllib.request
from datetime import datetime, timedelta, timezone
from pathlib import Path
from typing import Any

import yaml
from mcp import ClientSession, types
from mcp.client.stdio import StdioServerParameters, stdio_client

from air_eval.digests import surface_digest, tool_digest

STABLE = re.compile(r"^\d+(\.\d+)*$")
LIST_TIMEOUT_SECONDS = 20.0
INSTALL_TIMEOUT_SECONDS = 600


def stable_versions(published: dict[str, str], cap: int) -> list[tuple[str, str]]:
    """Return up to ``cap`` most recent stable versions as (version, published_at), oldest first.

    ``published`` maps version to an ISO 8601 timestamp. Pre-release versions
    (anything that is not dotted digits) are dropped.
    """
    stable = sorted((when, version) for version, when in published.items() if STABLE.match(version))
    return [(version, when) for when, version in stable[-cap:]]


def published_versions(ecosystem: str, package: str) -> dict[str, str]:
    """Return version to publish time for a package from its registry."""
    if ecosystem == "npm":
        out = subprocess.run(
            ["npm", "view", package, "time", "--json"], check=True, capture_output=True, text=True, timeout=120
        ).stdout
        return {k: v for k, v in json.loads(out).items() if k not in ("created", "modified")}
    if ecosystem == "pypi":
        with urllib.request.urlopen(f"https://pypi.org/pypi/{package}/json", timeout=60) as response:
            releases = json.load(response)["releases"]
        return {v: files[0]["upload_time_iso_8601"] for v, files in releases.items() if files}
    raise ValueError(f"unknown ecosystem {ecosystem!r}")


def day_after(published_at: str) -> str:
    """Return the RFC 3339 timestamp 24 hours after an ISO 8601 publish time."""
    when = datetime.fromisoformat(published_at.replace("Z", "+00:00")) + timedelta(days=1)
    return when.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")


def root_cause(exc: BaseException) -> BaseException:
    """Return the first leaf of an exception group, or the exception itself."""
    while isinstance(exc, BaseExceptionGroup) and exc.exceptions:
        exc = exc.exceptions[0]
    return exc


def safe_name(package: str) -> str:
    """Return a directory name for a package name."""
    return package.replace("/", "__").replace("@", "")


def install(ecosystem: str, package: str, version: str, published_at: str, tmp: Path) -> list[str]:
    """Install one version under ``tmp`` and return the argv that starts the server.

    PyPI dependencies resolve as of the day after the release (``--exclude-newer``),
    because old releases with open dependency ranges do not start on current libraries.
    """
    if ecosystem == "npm":
        subprocess.run(
            ["npm", "install", "--prefix", str(tmp), "--no-save", "--ignore-scripts", "--no-audit", "--no-fund",
             f"{package}@{version}"],
            check=True, capture_output=True, text=True, timeout=INSTALL_TIMEOUT_SECONDS,
        )
        root = tmp / "node_modules" / package
        manifest = json.loads((root / "package.json").read_text(encoding="utf-8"))
        entry = manifest.get("bin")
        if isinstance(entry, dict):
            entry = next(iter(entry.values()), None)
        if not isinstance(entry, str):
            raise RuntimeError(f"{package}@{version} declares no bin")
        return ["node", str(root / entry)]
    venv = tmp / ".venv"
    subprocess.run(["uv", "venv", "--python", "3.12", str(venv)], check=True, capture_output=True, text=True, timeout=120)
    subprocess.run(
        ["uv", "pip", "install", "--python", str(venv / "bin" / "python"), "--exclude-newer", day_after(published_at),
         f"{package}=={version}"],
        check=True, capture_output=True, text=True, timeout=INSTALL_TIMEOUT_SECONDS,
    )
    return [str(venv / "bin" / package)]


def sandbox_prefix(tmp: Path) -> list[str]:
    """Return the bubblewrap argv: read-only filesystem, no network, writable ``tmp`` only."""
    return [
        "bwrap", "--unshare-net", "--die-with-parent", "--ro-bind", "/", "/", "--dev", "/dev", "--proc", "/proc",
        "--tmpfs", "/tmp", "--bind", str(tmp), str(tmp), "--chdir", str(tmp),
    ]


async def list_surface(argv: list[str], env: dict[str, str], stderr_path: Path) -> dict[str, Any]:
    """Start a server over stdio and return its initialize result and full tool list in wire form."""
    params = StdioServerParameters(command=argv[0], args=argv[1:], env=env)
    with stderr_path.open("w", encoding="utf-8") as errlog:
        async with stdio_client(params, errlog=errlog) as (read, write):
            async with ClientSession(read, write, read_timeout_seconds=LIST_TIMEOUT_SECONDS) as session:
                init = await session.initialize()
                tools: list[dict[str, Any]] = []
                cursor: str | None = None
                while True:
                    page = await session.list_tools(
                        params=types.PaginatedRequestParams(cursor=cursor) if cursor else None
                    )
                    tools += [t.model_dump(by_alias=True, exclude_none=True, mode="json") for t in page.tools]
                    cursor = page.next_cursor
                    if not cursor:
                        break
    return {
        "protocolVersion": init.protocol_version,
        "serverInfo": init.server_info.model_dump(by_alias=True, exclude_none=True, mode="json"),
        "capabilities": init.capabilities.model_dump(by_alias=True, exclude_none=True, mode="json"),
        "instructions": init.instructions,
        "tools": tools,
    }


def snapshot_version(candidate: dict[str, Any], version: str, published_at: str) -> dict[str, Any]:
    """Install, start, list, and describe one version. Failures are recorded, not raised."""
    record: dict[str, Any] = {
        "ecosystem": candidate["ecosystem"], "package": candidate["package"], "version": version,
        "published_at": published_at, "ok": False, "error": None,
    }
    tmp = Path(tempfile.mkdtemp(prefix="air-rq1-"))
    try:
        scratch = tmp / "scratch"
        scratch.mkdir()
        (tmp / "home").mkdir()
        argv = install(candidate["ecosystem"], candidate["package"], version, published_at, tmp)
        argv += [str(arg).replace("{scratch}", str(scratch)) for arg in candidate.get("args", [])]
        env = {"PATH": "/usr/bin:/bin", "HOME": str(tmp / "home"), **{k: str(v) for k, v in candidate.get("env", {}).items()}}
        record["launch"] = [a.replace(str(tmp), "$TMP") for a in argv]
        stderr_path = tmp / "stderr.log"
        try:
            surface = asyncio.run(asyncio.wait_for(list_surface(sandbox_prefix(tmp) + argv, env, stderr_path), 60))
        finally:
            record["stderr_tail"] = stderr_path.read_text(encoding="utf-8", errors="replace")[-2000:].replace(str(tmp), "$TMP") if stderr_path.exists() else ""
        record.update(surface)
        record["digests"] = {
            "surface": surface_digest(surface["tools"], surface["instructions"]),
            "tools": {tool["name"]: tool_digest(tool) for tool in surface["tools"]},
        }
        record["ok"] = True
    except (Exception, asyncio.CancelledError) as raised:  # noqa: BLE001 - every failure kind is a data point
        exc = root_cause(raised)
        detail = exc.stderr[-500:] if isinstance(exc, subprocess.CalledProcessError) and exc.stderr else str(exc)
        record["error"] = f"{type(exc).__name__}: {detail}"[:1000]
    finally:
        shutil.rmtree(tmp, ignore_errors=True)
    return record


def collect(candidates_path: Path, out_dir: Path, cap: int, only: str | None) -> int:
    """Collect every missing snapshot. Returns the number of failed versions."""
    candidates = yaml.safe_load(candidates_path.read_text(encoding="utf-8"))
    failures = 0
    for candidate in candidates:
        if only is not None and candidate["package"] != only:
            continue
        target = out_dir / candidate["ecosystem"] / safe_name(candidate["package"])
        target.mkdir(parents=True, exist_ok=True)
        versions = stable_versions(published_versions(candidate["ecosystem"], candidate["package"]), cap)
        for version, published_at in versions:
            path = target / f"{version}.json"
            if path.exists():
                continue
            record = snapshot_version(candidate, version, published_at)
            path.write_text(json.dumps(record, indent=2, sort_keys=True) + "\n", encoding="utf-8")
            failures += 0 if record["ok"] else 1
            status = f"{len(record['tools'])} tools" if record["ok"] else record["error"].splitlines()[0][:120]
            print(f"{candidate['package']}@{version}: {status}", flush=True)
    return failures


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--candidates", type=Path, default=Path(__file__).with_name("candidates.yaml"))
    parser.add_argument("--out", type=Path, required=True)
    parser.add_argument("--cap", type=int, default=40)
    parser.add_argument("--only", help="collect a single package")
    args = parser.parse_args(argv)
    if sys.platform != "linux":
        raise SystemExit(
            "RQ1 collection starts third-party servers inside bubblewrap and runs on Linux only; "
            "copy data/rq1/snapshots from a Linux run and use air_eval.rq1.replay instead"
        )
    failures = collect(args.candidates, args.out, args.cap, args.only)
    print(f"failed versions: {failures}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Replay every pinning scheme over the consecutive-version transitions of the collected snapshots.

Every real release transition is assumed benign, so each alert counted here is
a false alert under that assumption. Writes ``rq1-transitions.csv`` (one row per
transition) and ``rq1-summary.md`` (counts per server and per class).
"""

from __future__ import annotations

import argparse
import csv
import json
import sys
from collections import Counter
from pathlib import Path
from typing import Any

from air_eval.rq1.classify import CLASS_ORDER, classify
from air_eval.rq1.schemes import SCHEMES
from air_eval.stats import wilson_interval


def load_server(directory: Path) -> tuple[list[dict[str, Any]], int]:
    """Return the successful snapshots of one server ordered by publish time, and the failed count."""
    records = [json.loads(path.read_text(encoding="utf-8")) for path in sorted(directory.glob("*.json"))]
    ok = sorted((r for r in records if r["ok"]), key=lambda r: r["published_at"])
    return ok, len(records) - len(ok)


def transitions(snapshot_root: Path) -> tuple[list[dict[str, Any]], dict[str, dict[str, int]]]:
    """Return one row per consecutive-version transition, and per-server snapshot counts."""
    rows: list[dict[str, Any]] = []
    servers: dict[str, dict[str, int]] = {}
    for directory in sorted(p for p in snapshot_root.glob("*/*") if p.is_dir()):
        snapshots, failed = load_server(directory)
        if not snapshots and failed == 0:
            continue
        package = snapshots[0]["package"] if snapshots else directory.name
        servers[package] = {"snapshots": len(snapshots), "failed": failed}
        for old, new in zip(snapshots, snapshots[1:]):
            t = classify(old, new)
            row: dict[str, Any] = {
                "package": package,
                "from": old["version"],
                "to": new["version"],
                "class": "description-only" if t.primary == "description-change" else t.primary,
                "labels": " ".join(sorted(t.labels)),
                "added": len(t.added),
                "removed": len(t.removed),
                "changed": len(t.changed),
                "expansions": "; ".join(t.expansions),
            }
            for name, scheme in SCHEMES.items():
                row[f"flag:{name}"] = int(scheme(old, new))
            rows.append(row)
    return rows, servers


def summary_markdown(rows: list[dict[str, Any]], servers: dict[str, dict[str, int]]) -> str:
    """Render the pilot summary: transitions per class and false alerts per scheme."""
    n = len(rows)
    lines = [
        "# RQ1 mini-corpus (pilot)",
        "",
        f"Measured. {len(servers)} servers, {sum(s['snapshots'] for s in servers.values())} snapshots, "
        f"{sum(s['failed'] for s in servers.values())} versions failed to start, {n} consecutive-version transitions. "
        "Every transition is a published release and is assumed benign, so each alert is a false alert under that assumption.",
        "",
        "## Transitions per class",
        "",
        "| Class | Transitions |",
        "|---|---|",
    ]
    classes = Counter(row["class"] for row in rows)
    order = ["description-only" if c == "description-change" else c for c in CLASS_ORDER]
    lines += [f"| {name} | {classes.get(name, 0)} |" for name in order]
    lines += ["", "## Alerts per scheme", "", "| Scheme | Alerts | Share of transitions | Wilson 95% interval |", "|---|---|---|---|"]
    for name in SCHEMES:
        k = sum(row[f"flag:{name}"] for row in rows)
        low, high = wilson_interval(k, n)
        share = f"{k / n:.3f}" if n else "n/a"
        lines.append(f"| {name} | {k} | {share} | {low:.3f}–{high:.3f} |")
    lines += ["", "## Per server", "", "| Package | Snapshots | Failed versions | Transitions | description-only alerts | full-surface alerts |", "|---|---|---|---|---|---|"]
    for package, counts in servers.items():
        own = [row for row in rows if row["package"] == package]
        lines.append(
            f"| `{package}` | {counts['snapshots']} | {counts['failed']} | {len(own)} | "
            f"{sum(r['flag:description-only'] for r in own)} | {sum(r['flag:full-surface'] for r in own)} |"
        )
    return "\n".join(lines) + "\n"


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--snapshots", type=Path, required=True)
    parser.add_argument("--out", type=Path, required=True)
    args = parser.parse_args(argv)
    rows, servers = transitions(args.snapshots)
    args.out.mkdir(parents=True, exist_ok=True)
    fields = ["package", "from", "to", "class", "labels", "added", "removed", "changed", "expansions", *[f"flag:{n}" for n in SCHEMES]]
    with (args.out / "rq1-transitions.csv").open("w", newline="", encoding="utf-8") as handle:
        writer = csv.DictWriter(handle, fieldnames=fields)
        writer.writeheader()
        writer.writerows(rows)
    (args.out / "rq1-summary.md").write_text(summary_markdown(rows, servers), encoding="utf-8")
    print(f"{len(rows)} transitions over {len(servers)} servers")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Per-episode token and latency table for a harness run, folded from session JSONL files.

The session logs under the run's DSH_HOME are the source; the metrics recorded
in ``episodes.jsonl`` at run time (folded from SDK notifications) are compared
with them and any disagreement fails the report.
"""

from __future__ import annotations

import argparse
import csv
import json
import statistics
import sys
from pathlib import Path
from typing import Any

from air_eval.events import fold_events, read_session_events, session_log_path

COLUMNS = ("steps", "input_tokens", "output_tokens", "cache_read_tokens", "llm_ms", "ttft_ms", "decode_ms", "tool_ms", "tool_calls")


def episode_table(run_root: Path) -> list[dict[str, Any]]:
    """Return one row per episode with metrics re-folded from its session JSONL file."""
    rows: list[dict[str, Any]] = []
    for line in (run_root / "episodes.jsonl").read_text(encoding="utf-8").splitlines():
        recorded = json.loads(line)
        log = session_log_path(run_root / "home", recorded["session_id"])
        folded = fold_events(read_session_events(log)).to_row()
        mismatched = [key for key in COLUMNS if folded[key] != recorded[key]]
        if mismatched:
            raise ValueError(f"{recorded['session_id']}: session log disagrees with run-time metrics on {mismatched}")
        rows.append({
            "session_id": recorded["session_id"], "prompt_id": recorded["prompt_id"], "wall_s": recorded["wall_s"],
            **{key: folded[key] for key in COLUMNS}, "finish_reason": folded["finish_reason"],
        })
    return rows


def percentile(values: list[float], q: float) -> float:
    """Return the nearest-rank percentile of a non-empty list."""
    ordered = sorted(values)
    return ordered[max(0, min(len(ordered) - 1, round(q * len(ordered) + 0.5) - 1))]


def summary_markdown(rows: list[dict[str, Any]], manifest: dict[str, Any]) -> str:
    """Render measured per-episode statistics."""
    lines = [
        "# Per-episode tokens and latency (pilot)",
        "",
        f"Measured from session JSONL files. Model `{manifest['model']}` via `{manifest['provider']}`, arm `{manifest['arm']}`, "
        f"{len(rows)} episodes of `{manifest['prompts_file']}`, one repeat, no AIR plugins. These are short single-turn prompts; "
        "the figures do not predict benchmark episodes with tool loops.",
        "",
        "| Metric per episode | Mean | Median | p95 | Max |",
        "|---|---|---|---|---|",
    ]
    for key in ("wall_s", *COLUMNS):
        values = [float(row[key]) for row in rows]
        lines.append(
            f"| {key} | {statistics.fmean(values):.1f} | {statistics.median(values):.1f} | "
            f"{percentile(values, 0.95):.1f} | {max(values):.1f} |"
        )
    steps = sum(row["steps"] for row in rows)
    if steps:
        lines += ["", f"Measured: mean time to first token per model step {sum(row['ttft_ms'] for row in rows) / steps:.0f} ms over {steps} steps."]
    return "\n".join(lines) + "\n"


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--run", type=Path, required=True)
    parser.add_argument("--out", type=Path, required=True)
    args = parser.parse_args(argv)
    rows = episode_table(args.run)
    manifest = json.loads((args.run / "manifest.json").read_text(encoding="utf-8"))
    args.out.mkdir(parents=True, exist_ok=True)
    with (args.out / "episode-metrics.csv").open("w", newline="", encoding="utf-8") as handle:
        writer = csv.DictWriter(handle, fieldnames=list(rows[0]))
        writer.writeheader()
        writer.writerows(rows)
    (args.out / "episode-metrics.md").write_text(summary_markdown(rows, manifest), encoding="utf-8")
    print(f"{len(rows)} episodes")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Draw a fixed, stratified LongMemEval question subset."""

from __future__ import annotations

import argparse
import json
import random
import sys
from collections import defaultdict
from pathlib import Path
from typing import Any


def is_abstention(question_id: str) -> bool:
    """Abstention questions carry the ``_abs`` suffix."""
    return question_id.endswith("_abs")


def sample_ids(items: list[dict[str, Any]], n: int, seed: int) -> list[str]:
    """Return ``n`` question ids: one per question type first, the rest proportional to type size.

    The draw is deterministic for a given (items, n, seed). When the dataset has
    abstention questions and none was drawn, the last pick of the first type
    that has one is replaced by an abstention question of that type.
    """
    by_type: dict[str, list[str]] = defaultdict(list)
    for item in items:
        by_type[item["question_type"]].append(str(item["question_id"]))
    types = sorted(by_type)
    if n < len(types):
        raise ValueError(f"n={n} is smaller than the number of question types ({len(types)})")
    total = len(items)
    quota = {t: 1 for t in types}
    remaining = n - len(types)
    shares = {t: remaining * len(by_type[t]) / total for t in types}
    for t in types:
        quota[t] += int(shares[t])
    leftover = n - sum(quota.values())
    for t in sorted(types, key=lambda t: (-(shares[t] - int(shares[t])), t))[:leftover]:
        quota[t] += 1

    rng = random.Random(seed)
    picked: dict[str, list[str]] = {}
    for t in types:
        pool = sorted(by_type[t])
        rng.shuffle(pool)
        picked[t] = pool[: quota[t]]
    if not any(is_abstention(q) for ids in picked.values() for q in ids):
        for t in types:
            candidates = sorted(q for q in by_type[t] if is_abstention(q))
            if candidates:
                picked[t][-1] = candidates[rng.randrange(len(candidates))]
                break
    return [q for t in types for q in picked[t]]


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--data", type=Path, required=True)
    parser.add_argument("--n", type=int, default=10)
    parser.add_argument("--seed", type=int, default=20260930)
    parser.add_argument("--out", type=Path, required=True)
    args = parser.parse_args(argv)
    items = json.loads(args.data.read_text(encoding="utf-8"))
    ids = sample_ids(items, args.n, args.seed)
    args.out.write_text(json.dumps({"source": args.data.name, "seed": args.seed, "question_ids": ids}, indent=2) + "\n", encoding="utf-8")
    print(f"wrote {len(ids)} question ids to {args.out}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""OpenAI-compatible chat-completions server that answers with recorded assistant turns.

The ingestion driver sets ``script`` to ``{user text: recorded reply}`` before
each turn. A request whose last user message has no scripted reply gets HTTP
404, so a harness request that the driver did not expect fails the turn
instead of inventing text.
"""

from __future__ import annotations

import json
import threading
import time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from typing import Any


def last_user_text(messages: list[dict[str, Any]]) -> str:
    """Return the text of the last user message of a chat-completions request."""
    for message in reversed(messages):
        if message.get("role") != "user":
            continue
        content = message.get("content")
        if isinstance(content, str):
            return content
        if isinstance(content, list):
            return "".join(p.get("text", "") for p in content if isinstance(p, dict) and p.get("type") == "text")
    return ""


class ReplayServer:
    """Serve ``POST /v1/chat/completions`` on ``127.0.0.1`` from ``script``."""

    def __init__(self) -> None:
        self.script: dict[str, str] = {}
        self.request_count = 0
        outer = self

        class Handler(BaseHTTPRequestHandler):
            def log_message(self, *_args: Any) -> None:
                return

            def do_POST(self) -> None:  # noqa: N802 - http.server API name
                body = json.loads(self.rfile.read(int(self.headers["Content-Length"])))
                outer.request_count += 1
                text = outer.script.get(last_user_text(body.get("messages", [])))
                if text is None:
                    payload = json.dumps({"error": {"message": "no recorded reply for this user message"}}).encode()
                    self.send_response(404)
                    self.send_header("Content-Type", "application/json")
                    self.send_header("Content-Length", str(len(payload)))
                    self.end_headers()
                    self.wfile.write(payload)
                    return
                base = {"id": "replay", "created": int(time.time()), "model": body.get("model", "replay")}
                usage = {"prompt_tokens": 0, "completion_tokens": 0, "total_tokens": 0}
                if body.get("stream"):
                    chunk = {**base, "object": "chat.completion.chunk"}
                    frames = [
                        {**chunk, "choices": [{"index": 0, "delta": {"role": "assistant", "content": text}, "finish_reason": None}]},
                        {**chunk, "choices": [{"index": 0, "delta": {}, "finish_reason": "stop"}]},
                        {**chunk, "choices": [], "usage": usage},
                    ]
                    self.send_response(200)
                    self.send_header("Content-Type", "text/event-stream")
                    self.end_headers()
                    for frame in frames:
                        self.wfile.write(f"data: {json.dumps(frame)}\n\n".encode())
                    self.wfile.write(b"data: [DONE]\n\n")
                    return
                payload = json.dumps({
                    **base, "object": "chat.completion", "usage": usage,
                    "choices": [{"index": 0, "message": {"role": "assistant", "content": text}, "finish_reason": "stop"}],
                }).encode()
                self.send_response(200)
                self.send_header("Content-Type", "application/json")
                self.send_header("Content-Length", str(len(payload)))
                self.end_headers()
                self.wfile.write(payload)

        self._httpd = ThreadingHTTPServer(("127.0.0.1", 0), Handler)
        self.port = int(self._httpd.server_address[1])
        self._thread = threading.Thread(target=self._httpd.serve_forever, name="lme-replay", daemon=True)

    @property
    def base_url(self) -> str:
        return f"http://127.0.0.1:{self.port}/v1"

    def __enter__(self) -> "ReplayServer":
        self._thread.start()
        return self

    def __exit__(self, *_exc: object) -> None:
        self._httpd.shutdown()
        self._httpd.server_close()
```

```python
are sent through the SDK; the ``lme-replay`` provider answers with the recorded
assistant turn, so no model generates text during ingestion. Session files
record wall-clock time, so the conversation date is stated in the first user
turn of each session.
"""

from __future__ import annotations

from datetime import datetime
from typing import Any

from air_eval.harness import RunDir, arm_patch, open_harness
from air_eval.longmemeval.replay_server import ReplayServer

NO_REPLY = "(no recorded reply)"
SYSTEM_PROMPT = (
    "You are a helpful personal assistant. Answer the user's question. "
    "When tools for searching earlier conversations are available, use them before you answer."
)


def parse_date(text: str) -> datetime:
    """Parse a LongMemEval date such as ``2023/05/20 (Sat) 02:21``."""
    return datetime.strptime(text, "%Y/%m/%d (%a) %H:%M")


def session_turns(session: list[dict[str, Any]]) -> tuple[list[tuple[str, str]], int]:
    """Pair each user turn with the assistant turn that follows it.

    Returns the pairs and the number of dropped turns (assistant turns with no
    preceding user turn). A user turn with no following assistant turn is
    paired with ``NO_REPLY``.
    """
    pairs: list[tuple[str, str]] = []
    dropped = 0
    pending: str | None = None
    for turn in session:
        if turn["role"] == "user":
            if pending is not None:
                pairs.append((pending, NO_REPLY))
            pending = turn["content"]
        elif pending is not None:
            pairs.append((pending, turn["content"] or NO_REPLY))
            pending = None
        else:
            dropped += 1
    if pending is not None:
        pairs.append((pending, NO_REPLY))
    return pairs, dropped


def ordered_sessions(item: dict[str, Any]) -> list[tuple[str, str, list[dict[str, Any]]]]:
    """Return (harness session id, date, turns) for each haystack session, oldest first."""
    rows = sorted(
        zip(item["haystack_dates"], item["haystack_session_ids"], item["haystack_sessions"]),
        key=lambda row: parse_date(row[0]),
    )
    return [(f"hist-{index:03d}-{session_id}", date, turns) for index, (date, session_id, turns) in enumerate(rows)]


def ingest_question(run: RunDir, item: dict[str, Any], replay: ReplayServer) -> dict[str, int]:
    """Replay every haystack session of one question into ``run.home``. Returns turn counts."""
    stats = {"sessions": 0, "turns": 0, "dropped_turns": 0, "no_reply_turns": 0}
    harness = open_harness(
        run, provider="lme-replay", model="replay", patches=(arm_patch("rq3-arm1"),),
        env={"AIR_EVAL_REPLAY_URL": replay.base_url, "AIR_EVAL_SYSTEM_PROMPT": SYSTEM_PROMPT},
    )
    with harness:
        for session_id, date, turns in ordered_sessions(item):
            pairs, dropped = session_turns(turns)
            stats["dropped_turns"] += dropped
            if not pairs:
                continue
            session = harness.start_session(session_id)
            stats["sessions"] += 1
            for index, (user_text, reply) in enumerate(pairs):
                text = f"[Conversation date: {date}]\n{user_text}" if index == 0 else user_text
                replay.script = {text: reply}
                result = session.run(text)
                if result.finish_reason != "completed" or result.final_response != reply:
                    raise RuntimeError(f"replay mismatch in {session_id} turn {index}: {result.finish_reason!r}")
                stats["turns"] += 1
                stats["no_reply_turns"] += reply == NO_REPLY
    return stats
```

- [ ] **Step 7: Write `air/eval/src/air_eval/longmemeval/judge.py`**

```python
"""LongMemEval answer judging with the benchmark's own prompts and a configurable judge model.

The prompt builder ``get_anscheck_prompt`` is loaded from the benchmark's
``evaluate_qa.py`` (fetched into the git-ignored data directory), so the prompt
text is the benchmark's and is not copied into this repository. The request
parameters match that script: temperature 0, ``max_tokens`` 10, and the label
is true when the reply contains ``yes``.
"""

from __future__ import annotations

import ast
from collections.abc import Callable
from pathlib import Path
from typing import Any

import openai

PromptBuilder = Callable[..., str]


def load_prompt_builder(evaluate_qa_path: Path) -> PromptBuilder:
    """Return ``get_anscheck_prompt`` from the benchmark script without running the script."""
    tree = ast.parse(evaluate_qa_path.read_text(encoding="utf-8"))
    functions = [node for node in tree.body if isinstance(node, ast.FunctionDef) and node.name == "get_anscheck_prompt"]
    if len(functions) != 1:
        raise ValueError(f"{evaluate_qa_path} does not define exactly one get_anscheck_prompt")
    namespace: dict[str, Any] = {}
    exec(compile(ast.Module(body=functions, type_ignores=[]), str(evaluate_qa_path), "exec"), namespace)  # noqa: S102
    return namespace["get_anscheck_prompt"]


def judge_one(client: openai.OpenAI, model: str, prompt: str) -> tuple[bool, str]:
    """Ask the judge model one yes/no question. Returns (label, raw reply)."""
    completion = client.chat.completions.create(
        model=model, messages=[{"role": "user", "content": prompt}], n=1, temperature=0, max_tokens=10
    )
    reply = (completion.choices[0].message.content or "").strip()
    return "yes" in reply.lower(), reply


def judge_rows(
    rows: list[dict[str, Any]], references: dict[str, dict[str, Any]], build_prompt: PromptBuilder,
    client: openai.OpenAI, model: str,
) -> list[dict[str, Any]]:
    """Label each hypothesis row; returns rows with ``judge``, ``label`` and ``judge_reply`` added."""
    out: list[dict[str, Any]] = []
    for row in rows:
        ref = references[row["question_id"]]
        prompt = build_prompt(
            ref["question_type"], ref["question"], ref["answer"], row["hypothesis"],
            abstention="_abs" in row["question_id"],
        )
        label, reply = judge_one(client, model, prompt)
        out.append({**row, "judge": model, "label": label, "judge_reply": reply})
    return out
```

```python
Every file is checked against a pinned SHA-256; a mismatch deletes the file
and fails, because a changed upstream file changes what the numbers mean.
"""

from __future__ import annotations

import argparse
import sys
import urllib.request
from pathlib import Path

from air_eval.harness import EVAL_ROOT, sha256_file

DATA_DIR = EVAL_ROOT / "data" / "longmemeval"
DATASET = "https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/resolve/main/"
FILES = {
    "longmemeval_oracle.json": (
        DATASET + "longmemeval_oracle.json",
        "821a2034d219ab45846873dd14c14f12cfe7776e73527a483f9dac095d38620c",
    ),
    "longmemeval_s_cleaned.json": (
        DATASET + "longmemeval_s_cleaned.json",
        "d6f21ea9d60a0d56f34a05b609c79c88a451d2ae03597821ea3d5a9678c3a442",
    ),
    "evaluate_qa.py": (
        "https://raw.githubusercontent.com/xiaowu0162/LongMemEval/main/src/evaluation/evaluate_qa.py",
        "ecce9c4c79dc89d99534ac17b383a5cbb5b9f0c69ee98adaf0684742e3d95251",
    ),
}


def fetch(name: str, data_dir: Path = DATA_DIR) -> Path:
    """Download one pinned file unless a verified copy exists. Returns its path."""
    url, expected = FILES[name]
    path = data_dir / name
    if path.is_file() and sha256_file(path) == expected:
        return path
    data_dir.mkdir(parents=True, exist_ok=True)
    urllib.request.urlretrieve(url, path)  # noqa: S310 - fixed https URLs above
    actual = sha256_file(path)
    if actual != expected:
        path.unlink()
        raise RuntimeError(f"{name}: SHA-256 {actual} does not match the pinned {expected}")
    return path


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("names", nargs="+", choices=sorted(FILES))
    args = parser.parse_args(argv)
    for name in args.names:
        print(fetch(name))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Render the committed LongMemEval smoke table from a run directory."""

from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path
from typing import Any


def _load(run: Path, name: str) -> dict[str, Any]:
    return json.loads((run / name).read_text(encoding="utf-8"))


def longmemeval_markdown(run: Path) -> str:
    """Render judge agreement and per-arm accuracy of the LongMemEval smoke run."""
    summary, manifest = _load(run, "summary.json"), _load(run, "manifest.json")
    a, b = summary["judges"]
    lines = [
        "# LongMemEval smoke: arms 1–2 and judge agreement",
        "",
        f"Measured. Dataset file `{manifest['dataset_file']}`, {len(manifest['question_ids'])} questions, answer model "
        f"`{manifest['model']}`, one repeat. Arm 1 has no memory and no session search; arm 2 has the upstream "
        "session-search tools only. **No AIR memory is in this run and no memory result is claimed.**",
        "",
        f"Judge agreement between `{a}` and `{b}` over {summary['pairs']} (question, arm) pairs: raw agreement "
        f"{summary['raw_agreement']:.3f}, Cohen's kappa {summary['cohen_kappa']:.3f}. Neither judge is the official "
        "GPT-4o judge, so these labels are not comparable with published LongMemEval numbers.",
        "",
        "| Judge / arm | Correct | Wilson 95% interval |",
        "|---|---|---|",
    ]
    for key, value in summary["accuracy"].items():
        low, high = value["wilson95"]
        lines.append(f"| `{key}` | {value['k']}/{value['n']} | {low:.3f}–{high:.3f} |")
    return "\n".join(lines) + "\n"


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--longmemeval", type=Path, required=True)
    parser.add_argument("--out", type=Path, required=True)
    args = parser.parse_args(argv)
    args.out.mkdir(parents=True, exist_ok=True)
    (args.out / "longmemeval-smoke.md").write_text(longmemeval_markdown(args.longmemeval), encoding="utf-8")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""LongMemEval smoke: ingest each sampled question, ask it under arms 1 and 2, judge with two models.

Arm 1 has no memory and no session search. Arm 2 adds the upstream
``session-query`` search tools over the ingested sessions. No AIR memory
plugin is involved, so this run shows the pipeline and a first judge-agreement
figure only.
"""

from __future__ import annotations

import argparse
import json
import shutil
import sys
import time
from pathlib import Path
from typing import Any

import openai

from air_eval.events import fold_events
from air_eval.harness import (
    EVAL_ROOT, ProfileError, RunDir, advertised_tools, arm_patch, create_run, ollama_model_digest, open_harness,
    sha256_file, write_manifest,
)
from air_eval.longmemeval.fetch import fetch
from air_eval.longmemeval.ingest import SYSTEM_PROMPT, ingest_question
from air_eval.longmemeval.judge import judge_rows, load_prompt_builder
from air_eval.longmemeval.replay_server import ReplayServer
from air_eval.stats import cohen_kappa, raw_agreement, wilson_interval

ARMS = ("arm1", "arm2")
SESSION_TOOLS = ["session_event_read", "session_event_search", "session_event_trace", "session_search", "session_trace"]
OLLAMA_URL = "http://127.0.0.1:11434/v1"


def ask(question_run: RunDir, item: dict[str, Any], arm: str, provider: str, model: str, max_tokens: int) -> dict[str, Any]:
    """Ask one question against a copy of the ingested home under one arm."""
    home = question_run.root / f"home-{arm}"
    shutil.copytree(question_run.home, home, symlinks=True)
    run = RunDir(root=question_run.root, home=home, workspace=question_run.workspace)
    harness = open_harness(
        run, provider=provider, model=model, patches=(arm_patch(f"rq3-{arm}"),), max_tokens=max_tokens,
        env={"AIR_EVAL_SYSTEM_PROMPT": SYSTEM_PROMPT},
    )
    started = time.monotonic()
    with harness:
        result = harness.run(f"Current date: {item['question_date']}. {item['question']}", session_id=f"ask-{arm}")
    expected = SESSION_TOOLS if arm == "arm2" else []
    seen = sorted(advertised_tools(result.events))
    if seen != expected:
        raise ProfileError(f"{arm}: model-visible tools {seen} differ from {expected}")
    return {
        "question_id": str(item["question_id"]), "question_type": item["question_type"], "arm": arm,
        "hypothesis": result.final_response, "wall_s": round(time.monotonic() - started, 3),
        **fold_events(result.events).to_row(),
    }


def agreement(labels: dict[str, list[dict[str, Any]]]) -> dict[str, Any]:
    """Compare two judges over the same (question, arm) rows; also give each judge's accuracy per arm."""
    (name_a, rows_a), (name_b, rows_b) = labels.items()
    a = [row["label"] for row in rows_a]
    b = [row["label"] for row in rows_b]
    out: dict[str, Any] = {
        "judges": [name_a, name_b], "pairs": len(a),
        "raw_agreement": round(raw_agreement(a, b), 4), "cohen_kappa": round(cohen_kappa(a, b), 4), "accuracy": {},
    }
    for name, rows in labels.items():
        for arm in ARMS:
            own = [row["label"] for row in rows if row["arm"] == arm]
            low, high = wilson_interval(sum(own), len(own))
            out["accuracy"][f"{name}/{arm}"] = {"k": sum(own), "n": len(own), "wilson95": [round(low, 4), round(high, 4)]}
    return out


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--run-id", required=True)
    parser.add_argument("--variant", choices=["s", "oracle"], default="s")
    parser.add_argument("--subset", type=Path, default=EVAL_ROOT / "subsets" / "longmemeval-smoke-10.json")
    parser.add_argument("--provider", default="ollama")
    parser.add_argument("--model", default="air-eval-qwen25")
    parser.add_argument("--judges", nargs=2, default=["qwen2.5:7b-instruct", "llama3.1:8b"])
    parser.add_argument("--max-tokens", type=int, default=1024)
    parser.add_argument("--runs-root", type=Path)
    args = parser.parse_args(argv)

    data_path = fetch("longmemeval_oracle.json" if args.variant == "oracle" else "longmemeval_s_cleaned.json")
    build_prompt = load_prompt_builder(fetch("evaluate_qa.py"))
    items = {str(item["question_id"]): item for item in json.loads(data_path.read_text(encoding="utf-8"))}
    question_ids = json.loads(args.subset.read_text(encoding="utf-8"))["question_ids"]
    runs_root = args.runs_root or EVAL_ROOT / "runs"
    top = create_run(args.run_id, runs_root, with_profile=False)
    write_manifest(
        RunDir.at(top.root), benchmark="longmemeval", variant=args.variant, dataset_file=data_path.name,
        dataset_sha256=sha256_file(data_path), subset=args.subset.name, question_ids=question_ids, arms=list(ARMS),
        provider=args.provider, model=args.model, model_digest=ollama_model_digest(args.model), judges=args.judges,
        label="smoke, n=10 questions, arms 1-2 only, local judges, no memory result claimed",
        arm_patches={f"rq3-{arm}": arm_patch(f"rq3-{arm}").read_text(encoding="utf-8") for arm in ARMS},
    )

    hypotheses: list[dict[str, Any]] = []
    ingest_log: list[dict[str, Any]] = []
    with ReplayServer() as replay:
        for index, question_id in enumerate(question_ids, start=1):
            item = items[question_id]
            question_run = create_run(f"{args.run_id}/q-{question_id}", runs_root)
            started = time.monotonic()
            stats = ingest_question(question_run, item, replay)
            ingest_log.append({"question_id": question_id, "ingest_s": round(time.monotonic() - started, 1), **stats})
            for arm in ARMS:
                hypotheses.append(ask(question_run, item, arm, args.provider, args.model, args.max_tokens))
            print(f"[{index}/{len(question_ids)}] {question_id}: {ingest_log[-1]}", flush=True)

    def dump(name: str, rows: list[dict[str, Any]]) -> None:
        (top.root / name).write_text("".join(json.dumps(row) + "\n" for row in rows), encoding="utf-8")

    dump("ingest.jsonl", ingest_log)
    dump("hypotheses.jsonl", hypotheses)
    client = openai.OpenAI(base_url=OLLAMA_URL, api_key="ollama")
    labels: dict[str, list[dict[str, Any]]] = {}
    for judge in args.judges:
        labels[judge] = judge_rows(hypotheses, items, build_prompt, client, judge)
        dump(f"judged-{judge.replace(':', '_').replace('/', '_')}.jsonl", labels[judge])
    summary = agreement(labels)
    (top.root / "summary.json").write_text(json.dumps(summary, indent=2) + "\n", encoding="utf-8")
    print(json.dumps(summary, indent=2))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```markdown
Python uv project that drives the harness through the upstream Python SDK and measures it. This is the measurement apparatus and three pilot results. It contains no AIR defence, pinning, or memory result. The design is in [../plans/spikes/06-evaluation.md](../plans/spikes/06-evaluation.md); the build plan is [../plans/2026-09-30-05-eval-pilot.md](../plans/2026-09-30-05-eval-pilot.md).

## Setup

Commands are shell-neutral: they run unchanged in bash and in Windows PowerShell.

    pnpm install                                   # repository root
    pnpm run build                                 # repository root
    pnpm -C air install                            # repository root
    uv run --no-project python air/eval/scripts/check_composition.py   # repository root; prints "composition ok"
    uv sync --group test                           # from air/eval; Python 3.12
    ollama create air-eval-qwen25 -f ollama/air-eval-qwen25.Modelfile  # from air/eval; repeat for air-eval-qwen3 and air-eval-llama31
    uv run pytest                                  # from air/eval; keyless tests
    uv run pytest -m live                          # from air/eval; needs Ollama and the models above

On Windows, clone the repository near the drive root and enable long paths; the run directories nest deeply. RQ1 collection needs Linux (bubblewrap); the other items run on both systems.

Every run gets its own `DSH_HOME` under `runs/<run-id>/home` with an `air-eval` profile: the upstream `sdk-minimal` tree plus the eval-only bundle `air/bundles/air-eval`. The runtime is the checkout's built `dsh` CLI. `runs/` and `data/` are git-ignored.

## Reading the pilot tables

- **RQ1:** real release transitions are assumed benign, so every alert is a false alert under that assumption. Versions that failed to start are counted and excluded from transitions. No malicious drift is in this corpus, so it says nothing about detection.
- **Tokens and latency:** folded from session JSONL files with the upstream `session-stats` definitions. The episodes are short single-turn prompts with no tool; the figures do not predict benchmark episodes.
- **LongMemEval:** ten questions, arms 1–2, local judges. Histories are replayed with today's wall-clock timestamps; the conversation date is text in the first user turn of each session. No memory result is claimed, and the labels are not comparable with published numbers.
```

## Follow-up plans

### AgentDojo banking pilot: native pipeline versus the undefended harness (spike 06 §8 item 1; part of E2 and E6)

This follow-up is now written as [plan 06](2026-10-03-06-agentdojo-pilot.md); where its text differs from the design notes below (for example three simulated users instead of two), plan 06 governs. See "Relationship to the other evaluation plan" above for the shared modules and one task order.

Goal: AgentDojo v1.2.2 banking suite (16 user tasks, 9 injection tasks, 144 pairs under `important_instructions`; 169 episodes per arm including the 9 injection tasks run as user tasks), one model, one repeat, arm N (AgentDojo's own pipeline) against arm H0 (harness, no AIR policy), reported as benign utility, utility under attack, and targeted attack success with Wilson intervals, labelled "pilot, n = 16 / 144, one repeat, no AIR defences".

Design, with the parts already exercised end to end in a scratch run on 2026-10-01:

- **MCP bridge** (`air_eval/agentdojo/mcp_bridge.py`): a low-level `mcp.server.lowlevel.Server` with `on_list_tools` and `on_call_tool`, served by `server.streamable_http_app(streamable_http_path="/mcp")` under uvicorn in a daemon thread on `127.0.0.1:<free port>`. It lists each suite function as `name`, `description`, `parameters.model_json_schema()` and executes `runtime.run_function(env, name, arguments)` against a binding that the pipeline swaps per episode; results are AgentDojo's `tool_result_to_str` YAML; an AgentDojo error string becomes an `isError` result. One bridge per harness runtime.
- **Harness row**: `mcp-agentdojo` (`@deepseek-ai/dsh-mcp-client`, `serverName: agentdojo`, `transport: streamable-http`, `url` from `AIR_EVAL_MCP_URL`, `failOnStartupError: true`, `reconnect.enabled: false`), disabled in the bundle and enabled by `profiles/arms/rq2-h0.patch.yml`. With `mcp-resources` disabled (already done in this plan's bundle) the model sees exactly the eleven `mcp__agentdojo__*` tools; without that, it also sees `list_mcp_resources` and calls it.
- **Pipeline element** (`pipeline.py`): one `BasePipelineElement` whose `query()` binds the episode's runtime and environment, runs one fresh SDK session, asserts the advertised tool names, and converts events to messages. **Converter** (`convert.py`): one assistant message per `assistant/message` event with `FunctionCall(function=<name without mcp__agentdojo__>, args=json.loads(arguments), id)`, one tool message per `tool/result`, and always a final assistant message (AgentDojo's `model_output_from_messages` requires it).
- **Runner**: iterate tasks and call `suite.run_task_with_pipeline(pipeline, task, injection_task, injections)`; its second return value is true when the injection goal was executed. Name both pipelines `<arm>-local-<model>` so the attack text addresses "Local model" in both arms. Persona: AgentDojo's default system message through `AIR_EVAL_SYSTEM_PROMPT`.
- **Native arm**: `AgentPipeline([SystemMessage, InitQuery, OpenAILLM(client, model, temperature=0.0), ToolsExecutionLoop([ToolsExecutor(), llm])])` against Ollama's `/v1` endpoint and the same `air-eval-*` model; wrap `client.chat.completions.create` to record usage and time.
- **Eval approval answerer plugin** (`air/packages/eval-approval-oracle`, `@air/dsh-eval-approval-oracle`): a `ctx.on('approval/request', ...)` terminal answerer with Config `mode: 'rubber-stamp' | 'never'` and `auditPath`, one JSON line per decision, mounted next to `@deepseek-ai/dsh-user-approval` in the bundle. In H0 no upstream row returns `ask`, so the expected ask count is 0; the plugin matters once permission rules exist, and the `diligent` simulated user needs a per-session policy file.
- **Dependencies to add**: `agentdojo==0.1.35` and `uvicorn==0.54.0` (both import cleanly on Python 3.12 with `mcp` 2.2.0 and `openai` 3.x).
- **Reporting**: reuse `report/tables.py` for the measured tokens per AgentDojo episode and recompute the budget of spike 06 §1.5.

Measured in that scratch run (`qwen2.5:7b-instruct`, banking, n = 5 episodes per arm): native 5.8 s per episode, harness 9.0 s per episode, harness mean 5,094 input and 313 output tokens per episode. Estimates from those figures: 15–20 min for the native arm and 25–35 min for the harness arm on 169 episodes; under $1 for both arms on `deepseek-flash` at off-peak list prices. Effort: estimate 4–5 days (bridge 1 d, pipeline and converter with tests 1.5 d, plugin with tests and README 1 d, runs and table 1 d), lower than spike 06's E2 figure because the design is already exercised.
