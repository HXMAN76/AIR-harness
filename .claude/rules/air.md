# AIR fork

This checkout is a fork that carries the AIR project on the `air/main` branch. Before working on anything under `air/` or `research/`, or changing upstream files for AIR, read `air/AGENTS.md`; it lists the reading order, the current state (research and plans done, no feature code yet, do not start the build until the owner says so), and the rules: stay out of tree, never commit to `master`, no custom session event types, record every upstream edit in `air/UPSTREAM-DELTA.md`.
